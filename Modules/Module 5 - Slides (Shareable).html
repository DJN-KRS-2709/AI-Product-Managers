From Chat → Agents

Year 3 of GenAI: model acts

  • Chat: model generates; human acts.
  • Copilot: model drafts; human approves + acts.
  • Agent: model plans, calls tools, observes, iterates. Model acts.
Four Traits of Agency

If a system has all four, it's an agent

Goals

Pursues a goal, not just responds.

Tool use

Calls functions on the world.

Memory

State persists.

Iteration

Observes results, re-plans.

The Agent Spectrum

Tool → Assistant → Agent → Autonomous

LevelBehaviour
ToolDoes one thing on request
AssistantDrafts, recommends
AgentPlans + calls tools + iterates
Autonomous AgentLong horizons unsupervised

Pick the lowest level that delivers the job.

Hidden Costs of Autonomy

Speed vs. reliability

  • Cascading errors — wrong tool call → wrong next step
  • Cost blowup — autonomous loops without stop conditions
  • Audit opacity — "the agent decided" is not an audit log
  • Drift — long-term memory pulls behaviour off-spec
Agentic Design Patterns

ReAct + Planner-Executor

ReAct

Reason → Act → Observe → loop

Single-agent. Bounded sequential tasks.

Planner-Executor

Planner decomposes; executors run; planner re-plans.

Parallel / long tasks.

Agentic Memory

Four flavours

TypeLifetime
Short-termOne task
Long-termAcross sessions
EpisodicSpecific past events
SemanticGeneral knowledge

Spec each one explicitly — including the no's.

Common Failure Modes

Spec for the failure

  • Hallucinated tool calls
  • Memory poisoning
  • Runaway loops
  • Silent handoff failure
  • Drift across sessions
The PM's Agent Control Panel

Five levers

  • Triggers — when does the agent activate?
  • Tools — what can it call?
  • Memory scope — what / how long?
  • Stop conditions — when does it hand back / shut down?
  • Observability — logs, traces, eval surface

Tool: M5 - Agent Control Panel.html — spec each lever; export.

Agent Workflow Spec (AWSpec)

Nine sections — the deliverable

  1. Goal
  2. Trigger
  3. Inputs
  4. Tools available
  5. Memory
  6. Pattern (ReAct / Planner-Executor)
  7. Stop conditions
  8. Handoff rules
  9. Eval hooks

Tool: M5 - Agent Workflow Spec Builder.html — spec all 9 sections, export.

The PM Decision Triangle

AI alone / AI + human / human alone

AI alone

Full execute. Low risk, high earned trust.

AI + human

Draft + approve. Default for high-risk.

Human alone

Agent declines, escalates.

The boundary contract between PM and agent.
