Fake-Good vs. Boring Killer

The two-question filter

Fake-Good

  • Demos brilliantly
  • No clear value frame
  • Loses to a platform feature in 6 months

Boring Killer

  • Looks dull on a slide
  • Ladders to a real value frame
  • Survives 3x cost stress

Draft

AI Solution Decision Matrix

Five axes. Score 1–5.

AxisQuestion
Value clarityDoes it ladder to a value frame?
Technical feasibilityCan current models do this?
Data availabilityDo you have / can you get the corpus?
Risk toleranceCan you tolerate wrong outputs?
Strategic fitDoes it earn company oxygen?

<3 average = don't ship. 4+ on all five = boring killer.

Responsible AI · strategic guardrails

Risk is a strategic lever

  • Compliance — regulatory (GDPR, EU AI Act)
  • Safety — content, prompt injection, misuse
  • Reliability — uptime, fallback paths
  • Reputation — public failure response playbook

Each guardrail is a sales asset for enterprise buyers.

The AI Strategy One-Pager

Seven blocks. One page.

  1. The bet (one sentence + value frame)
  2. The user / job
  3. The mechanic
  4. The autonomy (Suggest / Draft / Execute / Operate)
  5. The technical approach (prompt / RAG / fine-tune / agent)
  6. The risk + guardrail
  7. The success metric

Self-review checklist

Before you ship the one-pager

  • The bet is one sentence with a quantified outcome.
  • The mechanic is understandable by a non-PM.
  • The autonomy level is justified against Job × Risk.
  • The tech approach ladders to the Optimization Framework.
  • The success metric is measurable in 30 days.
