Module 4 · Individual format

Design AI-Native User Experiences

Chat-in-a-tab is the wrong default. AI-native UX is invisible by design.

End state: Juno user flow + trust-gap mitigations in 04-ai-ux/.

Why AI-Native UX Matters

The 95%-accuracy-with-bad-UX product loses

  • Reveal reasoning when it matters
  • Surface confidence visually
  • Let the user steer in one click
  • Get out of the way when the AI is wrong

UX is where trust is built or destroyed.

Invisible by Design

Anticipate, don't wait

Wrong

Juno is a chat tab. PM must remember it exists.

Right

Juno surfaces a risk panel in Slack the moment a P0 thread crosses 5 messages.

Mapping Value to UX Treatment

Pick UX by value frame, not aesthetic

Value frameUX treatment
CostBackground automation with audit trail
RevenueInline assist at the moment of decision
RiskProactive flag + reason + one-click action
DelightAnticipatory suggestion, dismissible
The AI Iceberg · 7 nodes

What you see vs. what runs

  1. Trigger
  2. Capture
  3. Retrieve
  4. Reason
  5. Act
  6. Surface
  7. Confirm / Correct

The Three AI-UX Trust Gaps

Close all three or you don't ship

GapQuestionMitigation
Black-boxCan the user see why?Reasoning, citations, "show your work"
HallucinationCould this confidently be wrong?Confidence cues, source links, escape hatches
ControlCan the user steer or stop?Undo, edit, regenerate, "don't suggest this again"

Tool: M4 - AI-UX Trust Gap Checker.html — score each gap, write mitigations, export to 04-ai-ux/trust-gaps.md.

Managing the Intelligence Tax

Cognitive load and latency are product surfaces

  • Spec p95 latency
  • Stream output (cheapest perceived-latency win)
  • Decide whether to show "Juno is reasoning…"
  • If the tax exceeds the value frame, kill the feature

Key takeaways

What you carry into M5

  1. Chat-in-a-tab is the wrong default.
  2. Invisible by design — anticipate intent.
  3. Map value → UX treatment, not aesthetic.
  4. Spec all 7 nodes of the AI Iceberg.
  5. Close all three trust gaps before shipping.
