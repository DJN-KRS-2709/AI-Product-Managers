Self-review checklist

  • All three layers have signals/checks specified
  • Each layer has a numeric pass bar
  • Each layer has a cadence
  • Each layer names who acts on it
  • Layer 2 references the human-rubric.md file
  • Layer 3 has a versioned golden set
  • At least one hard gate is defined
