A complete AI user flow, broken into the four pillars. Read each row top-to-bottom — HR Agent mirrors the same logic Juno uses, just in a different domain.

HR Agent · Pillar 1 — Trigger

Signal type

User action · employee opens the HR Agent app or clicks a vacation-related notification.

Specific signal

Page load on /hr-agent with the user’s session token. The agent doesn’t wait for them to type.

Surface response

Agent welcome card appears with two suggested intents: Ask a question and Enter vacation. Status: “Loaded your team’s policy in 0.4s.”

HR Agent · Pillar 2 — Processing State

Hidden logic

1. Classify intent → question or task.
2. Path A (Question): RAG retrieval over HR-policy KB → cite policy doc.
3. Path B (Task): tool call to Workday API → submit vacation request.

Handshake breadcrumbs

“Scanning policy docs…” (Path A) or “Submitting to Workday…” (Path B). Each runs < 2s.

Router decision

Question intent → RAG. Task intent → Tool/API. Confidence < 70% → route to clarification step.

HR Agent · Pillar 3 — Presentation

Placement maneuver

Inline & Embedded for both paths — the answer or confirmation lands directly in the agent chat surface.

Generated output

Path A: AI-generated answer + a clickable “Source: 2024 Policy §3.2” link. Path B: confirmation card + link to the new Workday request + 1-click cancel.

Why this maneuver

Value = automation. The user wanted an answer or an action, not a UI to navigate. Inline keeps them in flow.

HR Agent · Pillar 4 — Feedback Loop

Kill switch

Every confirmation card has a one-click “Cancel request” + “Talk to a human” escalation that opens a support ticket.

Training signal

Cancel within 30s → logged as low_confidence_action. Five within a week → route this employee’s intents through clarification by default.

Fail-safe

RAG returns no policy match → agent says “I couldn’t find a policy that matches this exactly. Want me to open a ticket with HR?” Never invents a policy.

PM takeaway: the surface (chat agent) is simple. The 4-pillar structure underneath is what makes it trustworthy. Apply the same structure to Juno.
