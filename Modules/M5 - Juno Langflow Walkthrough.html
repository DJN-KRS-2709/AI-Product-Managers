Juno Langflow Walkthrough

Open Langflow docs ↑

Hand your AWSpec to a real agent runtime and watch the wiring come alive. Optional · not required for course completion. Two paths below — pick one based on time you have. Captures all six steps and exports screenshots into 05-agentic-workflows/langflow-screenshots/.

Before you start: install Langflow (Docker or pip), grab an OPENAI_API_KEY with ~$5 credit, and have your AWSpec markdown open for reference.
Path 1 · Import the starter Juno Agent

Best for understanding how each AWSpec section maps to a real Langflow node graph — without building from scratch.

1

Install + launch Langflow

Pick the install method that fits your setup:

  • Docker (recommended): docker run -p 7860:7860 langflowai/langflow:latest
  • pip: uv pip install langflow && langflow run
  • Open http://localhost:7860. You should see the Langflow workspace.
2

Import the Juno starter graph

Click Import flow in the top right. Pick the file juno-project-template/05-agentic-workflows/Juno Agent.json.

You should see a graph with: a chat trigger, a RAG retriever placeholder, an OpenAI LLM node, a confidence guardrail node, and a Slack post node.

3

Add your OpenAI key

Open Settings → Variables. Add a new variable:

  • Name: OPENAI_API_KEY
  • Value: paste your key (sk-…)
  • Type: Credential — never plaintext.

Then in the OpenAI LLM node, set the API key field to $OPENAI_API_KEY.

4

Replace the RAG placeholder

The starter ships with a Mock retriever node that returns canned chunks. For a real run, swap it for a real vector store.

  • Drag a Chroma or Pinecone retriever into the canvas.
  • Point it at your M3 KB index (RocketShip Strategy One-Pager + transcripts).
  • Wire its output to the LLM node’s context input.
  • Delete the mock retriever.
5

Set your confidence threshold

Open the Guardrail node. Match the threshold to the value you specced in your agent-control-panel.md.

  • Threshold: e.g. 0.70 → below this, the agent escalates.
  • Above: route to Slack post node.
  • Below: route to PM-review channel with the full reasoning trace.
6

Run + capture screenshots

Click Run in Langflow. In the Playground, paste a sample P0 thread (or use the canned one in the starter). Verify the agent:

  • Retrieves at least 3 KB chunks with sources.
  • Emits a confidence score.
  • Routes correctly through the guardrail.

Screenshot the canvas + the playground output. Save into 05-agentic-workflows/langflow-screenshots/. Commit + push.

Definition of done: screenshots committed to 05-agentic-workflows/langflow-screenshots/ + a one-paragraph reflection in 05-agentic-workflows/langflow-notes.md on what surprised you compared to your AWSpec.
Path 2 · Rebuild Juno from scratch

Best for understanding how each AWSpec section maps to a real Langflow node graph — node by node.

1

Drop the trigger

Drag a Chat input (or Webhook for production) onto the canvas. This is your AWSpec Trigger — the entry point.

  • For local testing: Chat input works fine.
  • For Slack hookup: use Webhook + a payload schema mapping the Slack event.
2

Add a vector store retriever

Drag a Chroma or Pinecone retriever. Configure it against your M3 KB index.

  • Top-K: 6 (matches your M3 PRD).
  • Embedding model: text-embedding-3-small — same as the index.
  • Filter: optional — e.g. category=strategy.
3

Wire the LLM with a North Star prompt

Drag OpenAI. Paste your North Star from agent-control-panel.md as the system prompt. Wire the retriever output to context.

  • Model: gpt-4o-mini for cost; gpt-4o for quality.
  • Temperature: 0.2 — agents should be boring.
  • Output format: JSON schema with {risks, confidence, citations}.
4

Add a confidence guardrail

Drag a Conditional (or Custom code) node. Read output.confidence from the LLM JSON. Branch on the threshold from your control panel.

  • True branch: forward to Slack post.
  • False branch: forward to PM review queue with the full reasoning trace.
5

Wire the action nodes (tools)

Drag a Slack post node + a Webhook for the PM-review queue. These are your AWSpec tools — one per write boundary.

  • Slack post → channel: #pm-daily. Restricted in your Access Control rule.
  • Webhook → PM review URL. Carries the full reasoning trace.
  • Both nodes have max_retries: 2 — matches your stop conditions.
6

Run + iterate

Open the Playground. Paste a sample P0 thread. Watch the trace.

  • If confidence is too low → tighten the system prompt or up the Top-K.
  • If the agent invents customer names → add an explicit “never invent” line to the North Star.
  • If retrieval misses the strategic pillar → check the embedding index for chunking issues.

Screenshot the canvas + the playground trace. Commit to 05-agentic-workflows/langflow-screenshots/.

Definition of done: screenshots + reflection committed. Bonus: export your final flow as JSON and replace the starter Juno Agent.json in your repo.
