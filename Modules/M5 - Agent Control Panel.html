Rules of engagement · the contract

Per source slide 24. Four contracts the PM owns — one per axis of risk.

🔐Agency Permission

Define the autonomy threshold. e.g. agent can draft a $5k quote but cannot hit Send.

🔑Access Control

Identify the read/write boundaries for every tool and database.

↩️Fallback Protocols

Specify the fallback experience when loops break or gates trigger.

🚨Checkpoints

Set red-zone triggers for human intervention based on risk, value, or ambiguity.

Self-review · before you commit

  • Stop conditions name a numeric max_steps + a wall-clock timeout.
  • Tool outputs include a confidence/score field for every retrieval-flavour tool.
  • Confidence thresholds map to actions, not just labels.
  • North Star is a single goal sentence the agent re-reads every loop.
  • Each rule of engagement names something the agent cannot do, not just what it can.
